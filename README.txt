FREDBEAR'S FAMILY DINER — FIXED AUDIO EDITION
=============================================

This is a clean rebuild to fix the earlier file problems.

WHAT IS INCLUDED
----------------
- Fully visible office
- Left and right doors
- Left and right door lights
- Visible Fredbear at the left door when the light is on
- Visible Spring Bonnie at the right door when the light is on
- 4 visible camera rooms:
  1. Main Stage
  2. Dining Area
  3. Party Hall
  4. Safe Room
- Fredbear visible on cameras
- Spring Bonnie visible on cameras
- Easy mode with slow movement
- About 10 seconds to react at a doorway
- Slower power drain
- Fredbear jumpscare
- Spring Bonnie jumpscare
- Camera static sound
- Door sound
- Light sound
- Jumpscare sound
- 6 AM sound
- Original phone calls at the start of Nights 1-5
- Skip Call button
- Sound On/Off button
- New Game and Continue

IMPORTANT ABOUT SOUND
---------------------
The game generates its sound effects in JavaScript, so there are no missing
MP3 files.

The phone call uses the browser's built-in speech voice. On iPad/Safari,
sound begins after you tap NEW GAME or CONTINUE because browsers require
a user tap before audio can start.

GITHUB PAGES
------------
Upload these three files to the root of your repository:
- index.html
- style.css
- game.js

Then:
Settings > Pages > Deploy from a branch > main > /(root) > Save.

If GitHub already has older versions, replace all three old files with
these new ones so they match.

NOTE

This is a fan-made game. It uses original placeholder drawings, original
phone-call text, and generated sound effects instead of official FNAF
