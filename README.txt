FREDBEAR'S FAMILY DINER — EASY VISIBLE EDITION
================================================

This version adds:
- A fully visible office area with desk, fan, phone, papers, cup, poster, clock, floor, and both doors
- Camera rooms that actually look different inside:
  CAM 1 Main Stage
  CAM 2 Dining Area
  CAM 3 Party Hall
  CAM 4 Safe Room
- Visible Fredbear and Spring Bonnie drawings on the camera feed
- Easy Mode:
  slower animatronics
  slower power drain
  about 8 seconds to react when an animatronic reaches a door
- Fredbear jumpscare
- Spring Bonnie jumpscare
- Multiple nights
- New Game and Continue

Upload index.html, style.css, and game.js to the root of a GitHub repository.
For GitHub Pages:
Settings > Pages > Deploy from a branch > main > /(root) > Save.

This is a fan-made game starter and does not include official FNAF art, audio,
models, textures, or copied game assets.
